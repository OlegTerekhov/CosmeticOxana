# BEREG WordPress theme

Тема находится в папке wordpress-theme/bereg.

## Что уже подключено
- Дизайн BEREG берётся из существующих CSS/style.css и CSS/light-background.css в корне сайта.
- Старая JS/app.js не подключается: она обслуживала статический магазин и Supabase, поэтому её нельзя запускать поверх WooCommerce.
- Главная страница использует WooCommerce shortcode для вывода реальных товаров.
- Каталог, карточка товара, корзина и кабинет используют штатные страницы WooCommerce.

## Категории товаров
При импорте товаров создать категории со слагами:
- anapa — Анапская косметика
- black-sea — Магия Чёрного моря

## Перед установкой на REG.RU
1. Убедиться, что WooCommerce установлен и активирован.
2. Проверить, что файлы CSS/style.css, CSS/light-background.css и папка images находятся в корне сайта либо перенести их в тему и изменить пути.
3. Загрузить архив темы bereg.zip через Внешний вид → Темы → Добавить новую → Загрузить тему.
4. Активировать тему только после проверки на отдельном тестовом адресе.
5. Импортировать товары и проверить категории, изображения, цены, корзину и оформление заказа.
6. Только после проверки на тесте переключать основную тему.

Тема не содержит платёжных ключей и не подключает эквайринг автоматически.
