# БЕРЕГ — косметика Чёрного моря

Мобильный магазин двух брендов юга России: «Анапская косметика» и «Чёрное море».

## Возможности
- Адаптивный интерфейс с фиксированной нижней навигацией из пяти разделов.
- Дневная и ночная морские темы с сохранением выбора.
- Каталоги двух брендов и сортировка по цене.
- Добавление товаров в корзину, изменение количества и расчёт суммы.
- Избранное с сохранением в браузере.
- Демонстрационная страница контактов.

## Запуск
Откройте `index.html` в браузере. Для публикации включите GitHub Pages в настройках репозитория: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Важно
Каталог и цены сейчас демонстрационные, изображения используются как временные визуальные заглушки и не подтверждают состав или упаковку реальных товаров. Перед запуском продаж замените карточки на утверждённые товары, реальные фотографии, цены, контакты и подключите оформление заказов.

Сделано на HTML, CSS и JavaScript без сборщика и платных API.
